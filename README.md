# olum-icons 

## Installation
```
npm install
```

### Development server
```
npm run dev
```

### Build for production
```
npm run build
```

See [Documentation](https://olumjs.top/docs)

## Contributing
Thanks for wanting to help make olum-icons better! 💙 Bug fixes, new features, and docs improvements are all welcome.

### Step by step
1. **Fork** the repo and clone your fork:
   ```bash
   git clone https://github.com/<your-username>/olum-icons.git
   cd olum-icons
   ```
2. **Make sure you're up to date** with `main`:
   ```bash
   git fetch origin
   git checkout main
   ```
3. **Create your own branch from it:**
   ```bash
   git checkout -b feat/my-awesome-feature
   # or: git checkout -b fix/describe-the-bug
   ```
4. **Install dependencies:**
   ```bash
   npm install
   ```
5. **Make your change.** Source lives in `src/` and the generator scripts in `scripts/`. Keep the change focused: one feature or fix per PR.
6. **Preview your change** with `npm run dev`. Note that `docs/` is generated by `npm run build` — do not edit it by hand.
7. **Commit** using a clear message, following the existing style:
   ```
   feat: add /usage route
   fix: describe the bug
   ```
8. **Push** your branch to your fork:
   ```bash
   git push origin feat/my-awesome-feature
   ```
9. **Open a Pull Request** against `main`. Describe what changed, why, and include a screenshot or small example if it's user-facing.

### PR checklist
- [ ] Branched from the latest `main`
- [ ] PR targets `main`
- [ ] One focused change, clear commit messages

Questions or unsure about an idea? Ask in [Discord](https://discord.gg/2zK7tb2Cg9) before you start — we're happy to help.
