# Attribution & Third-Party Licenses

`olum-icons` is a wrapper that redistributes icons from three upstream projects.
The wrapper's own code is MIT licensed, see [LICENSE.md](./LICENSE.md). The icons
themselves remain under their original licenses, reproduced in full below.

## Notice of modification

The icons distributed in this package have been **modified** from their original
form. No artwork was redrawn, but every icon was processed as follows:

- optimized with [SVGO](https://github.com/svg/svgo), which rewrites path data,
  merges and reorders attributes, and collapses whitespace
- comments, including inline license headers, were stripped from the SVG markup
  (this file carries that attribution instead)
- files were renamed to PascalCase and wrapped as JavaScript string exports
